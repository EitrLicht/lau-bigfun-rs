# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's **Security** tab ("Report a vulnerability"), not as a public issue.

This is a hobby project maintained on a best-effort basis: there is no bug bounty and no guaranteed response time.

## Scope

In scope: anything that lets a crafted archive or filelist make the tool write outside its output directory, run code, or exhaust memory.

Out of scope: crashes or errors on malformed archives. These are ordinary bugs; please file them as issues.
